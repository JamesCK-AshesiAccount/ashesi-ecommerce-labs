# Ashesi E-Commerce Labs

E-Commerce laboratory projects developed using PHP, MySQL, HTML, CSS and JavaScript at Ashesi University.

This repository collects Vanilla pathway coursework. It is intended to remain private unless the owner explicitly decides otherwise.

## Labs

| Folder | Project |
| --- | --- |
| `lab-1/` | Shoppn source copy, included here at the owner’s request. |
| `lab-2-shoppn/` | Shoppn, an MVC-inspired e-commerce application covering Tasks 1–10. |

Both lab folders intentionally contain the same Shoppn application source; the repository does not claim they are two distinct implementations.

Technologies: PHP, MySQL/MariaDB, HTML, CSS and Vanilla JavaScript. Local development uses Apache and XAMPP.

## Setup

1. Start Apache and MySQL in XAMPP.
2. Copy the lab folder you want to run into XAMPP's `htdocs` directory.
3. Follow that lab's README for database setup and configuration.
4. Keep real credentials in ignored configuration files. No customer records or password hashes are included.
